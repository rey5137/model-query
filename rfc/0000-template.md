# RFC NNNN — Title

- **Status:** draft | accepted | rejected | withdrawn
- **Affects:** spec ids this changes or adds (`R-AGG-08`, `INV-5`, …)
- **Discussion:** link

## Summary

One paragraph: what changes, for whom.

## Motivation

What is wrong or missing today. Include the concrete case that prompted this — a query that cannot be expressed, a
result that is wrong, a signature that permits a mistake.

## Design

The proposed API or behaviour, with code. State which existing rules change and which new `R-*` and `AC-*` ids this
introduces.

## Compatibility

Source and binary compatibility. What breaks, and whether `@Incubating` covers it. If it breaks something released,
justify why it cannot wait for the next major version.

## Alternatives

What else was considered and why it lost. "Do nothing" is always an alternative worth stating.

## Unresolved questions

What the RFC deliberately leaves open, and who decides.
