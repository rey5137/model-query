# RFCs

A change to a public signature, to a rule's meaning, or to an `INV-*` invariant needs an accepted RFC first
(`docs/spec/delivery/61-repo-release-governance.md` R-REL-14).

1. Open a GitHub Discussion to see whether the idea has legs.
2. Copy `0000-template.md` to `rfc/NNNN-short-title.md` (next free number) and open a PR.
3. An accepted RFC is merged. Implementation, tests and the spec update land together in a later PR.

Bug fixes, new tests, documentation and anything behind an existing escape hatch need no RFC.
