# Security Policy

## Supported versions

Until `1.0.0`, only the latest `0.x` release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/rey5137/model-query/security/advisories/new).

You can expect an acknowledgement within a week. Once a fix is released, the advisory is published with credit to the
reporter unless you prefer otherwise.
